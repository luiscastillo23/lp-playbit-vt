# PLAYBIT — Retro Handheld Gaming Console Landing Page

Pixel-perfect React + TypeScript + Vite + Tailwind CSS application replicating the PLAYBIT 2026 landing page.

## Execution with pnpm
```bash
pnpm install
pnpm run dev
```
Open `http://localhost:5173` in your browser.

## Execution with Docker
```bash
pnpm run docker:up
```
Stop containers with:
```bash
pnpm run docker:down
```
